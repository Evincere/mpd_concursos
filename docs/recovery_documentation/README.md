## 🚀 INICIO RÁPIDO

### Para ejecutar la recuperación completa:
1. Leer la **[GUÍA PRINCIPAL](./01_GUIA_RECUPERACION_COMPLETA.md)**
2. Verificar el sistema: `./recovery_scripts_external/00_verify_system_state.sh`
3. Seguir los pasos de la guía paso a paso

### Para entender el problema:
1. Leer el **[REPORTE DE INCIDENTE](./04_REPORTE_INCIDENTE_FINAL.md)**
2. Revisar el **[ESTADO ACTUAL](./05_ESTADO_ACTUAL.md)**
